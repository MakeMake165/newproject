# REDWAVE — Моя волна

В этой версии добавлена кнопка «Моя волна»: она случайным образом выбирает трек из загруженного каталога Jamendo и автоматически переключает на следующий трек по завершении текущего. Треки не повторяются, пока не перебрана доступная подборка; затем цикл начинается заново.

## Настройка
1. Распакуйте архив.
2. В `app.js` найдите `const JAMENDO_CLIENT_ID = 'ВСТАВЬ_СЮДА_СВОЙ_CLIENT_ID';` и вставьте свой публичный Jamendo Client ID между кавычками. Если Client ID уже настроен в старой версии сайта, перенесите его сюда.
3. Загрузите `index.html`, `style.css`, `app.js`, `README.md` в корень репозитория GitHub, замените старые файлы и нажмите **Commit changes**.
4. Дождитесь публикации Cloudflare Pages и обновите сайт.

## Важно
- «Моя волна» перемешивает доступные в текущем результате Jamendo треки; это не коммерческий каталог всех популярных песен.
- Если каталог содержит мало треков, разнообразие будет ограничено. Доступность аудиопотоков зависит от Jamendo и лицензий правообладателей.
- Jamendo Client ID — публичный идентификатор, не секретный API-ключ.
